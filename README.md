# BrandYou — Personal Brand & Portfolio Platform

BrandYou is a modern, high-fidelity portfolio and resume platform engineered for developers, designers, and creative professionals to establish their digital presence and craft ATS-friendly resumes.

## ✨ Features

- **Curated Architecture Templates**: Pre-designed, industry-specific portfolio templates (Developer, Designer, Creative, Professional, Healthcare, Legal, Entertainment, Student).
- **Interactive Portfolio Builder**: Real-time editor with responsive preview (Desktop, Tablet, Mobile) and instant live publishing flow.
- **ATS-Optimized & Executive Resume Templates**: High-contrast, clean minimal, creative edge, technical pro, and academic CV layouts ready for PDF export.
- **Modern Aesthetic**: Glassmorphism, smooth animations, dark themes, and responsive typography powered by Vanilla CSS.

## 🛠 Tech Stack

- **Framework**: React 19 + Vite
- **Routing**: React Router DOM v7
- **Icons**: Lucide React
- **Styling**: Vanilla CSS with modern custom design system

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/vaibhav02345/BrandYou.git
cd BrandYou
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
